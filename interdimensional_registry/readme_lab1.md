# DevOps_chill_operative

Привет из пространства реализации фич! В этот раз мы реализовали откаустойчивый NGINX, благодаря чему теперь есть **отказоустойчивость** (при условии рабочего сервера), ведь бэкенд делится **аж на два!** Сейчас расскажем и покажем как это работает.


# Файлы
Сделал много, аж на несколько папок набралось. Если говорить про ключевые:
*   **`docker-compose.yml`** — Инструкция для Docker. Запускает все файлы, объединяет в одну сеть, пробрасывает порты... Много делает в общем. Без него точно ничего не запустится.
*   **`default.conf`** — С этим файлом больше всего возни было. Никак не хотела работать переадресация, кастомная 404 тоже не работала... Но наша команда упертых разработчиков решила, что файл работать будет. **WAAAGH!**
*   **`check.sh`** — вот и автопроверка. Посмотрите в /photo результаты работы упертых разработчиков и выводы этого скрипта. Сам скрипт можно посмотреть прямо в этой папке (для удобства в /photo будет тоже). 

Остальные файлы в nginx нужны для общего функционирования приложения. Что-то содержит кастомные html, что-то отвечает за сертификаты, пароли, окружение и прочие штуки, которые показывать мы стесняемся. Что-то является воплощением силы дружбы нашей команды, но об этом ниже.
