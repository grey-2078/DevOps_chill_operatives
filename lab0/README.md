# DevOps_chill_operative

Самые неприятные события - те, которые нарушают комфорт нашей жизни. И речь не о заблокированных сервисах, а о событиях межпространственных масштабов. Представляю **реестр событий**, которые представляют некоторую угрозу реальности: от потных ладошек до **ДАННЫЕ УДАЛЕНЫ**. 


# Файлы
*   **`docker-compose.yml`** — Было бы круто, если б все это запускалось всего лишь одним файлом. Вот этот файл для этого и создан.
*   **`.env`** — мост к базе данных нужно починить. для этого нужно окружение. шаблон я дам. данные я не дам.
*   **`init_db.sql`** — Тут написана структура базы данных, тоже важный аспект. Предположим, носки. Остальное - сандали, которые пришлось на них надеть.
*   **`config.py`** — Инструкции, которые читает компутер чтобы знать что и куда из этого билда показывать (на сервак в докер-сети, либо на локалхост).
*   **`db_manager.py`** — Делает то же самое, что и обычный манагер. Только этот создан для базы данных: манагерит базу данных, заставляя работать так, как задумали разработчики. 
*   **`app.py`** — Создает кнопочки, которые можно тыкать. Если потыкать их и клавиатуру, то штуки записываются туда, куда должны. А куда не должны - не записываются.
